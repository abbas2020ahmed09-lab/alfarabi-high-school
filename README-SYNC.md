# 🔄 نظام مزامنة بيانات الفارابي

## 📋 المشكلة والحل

### المشكلة:
عند تحديث البيانات في لوحة التحكم (معلمين، أخبار، معرض، إلخ)، التغييرات تُحفظ فقط في المتصفح المحلي (localStorage) ولا تظهر للمستخدمين الآخرين الذين يشاهدون الموقع على GitHub Pages.

### الحل:
نظام مزامنة يدوي يعمل مع GitHub Pages - يسمح للمسؤولين بمشاركة التحديثات مع بعضهم البعض.

---

## 🚀 كيفية الاستخدام

### 1. للمسؤول الذي يقوم بالتحديثات:

1. **افتح لوحة تحكم المطور**
   - اذهب إلى الموقع الرئيسي
   - اضغط "إدارة الموقع"
   - أدخل رمز المطور: `DEV_MASTER_2024`

2. **قم بالتحديثات المطلوبة**
   - إضافة/تعديل/حذف المعلمين
   - إضافة/تعديل الأخبار
   - إضافة/تعديل صور المعرض
   - أي تحديثات أخرى

3. **صدّر البيانات**
   - في لوحة تحكم المطور، اضغط "🔄 مزامنة البيانات"
   - ستفتح صفحة المزامنة في نافذة جديدة
   - اضغط "📥 تصدير البيانات"
   - سيتم تحميل ملف JSON باسم: `alfarabi-data-YYYY-MM-DD.json`

4. **ارفع الملف إلى GitHub**
   - اذهب إلى مستودع GitHub الخاص بالموقع
   - ارفع ملف JSON إلى مجلد الموقع
   - تأكد أن الملف متوفر للعامة

---

### 2. للمسؤولين الآخرين لتحديث الموقع:

1. **احصل على ملف البيانات**
   - قم بتحميل ملف JSON من GitHub
   - أو اطلبه من المسؤول الذي قام بالتحديثات

2. **استورد البيانات**
   - افتح صفحة المزامنة (من لوحة تحكم المطور)
   - اضغط "📁 اختر ملف البيانات"
   - اختر ملف JSON الذي حصلت عليه
   - اضغط "فتح"

3. **تحقق من التحديثات**
   - اذهب إلى الموقع الرئيسي
   - حدث الصفحة (F5)
   - ستجد جميع التحديثات الجديدة

## ⚠️ ملاحظات هامة

### الأمان:
- لا تقم بمشاركة رموز الدخول (`ADMIN_FARABI_2024`, `DEV_MASTER_2024`)
- ملف البيانات يحتوي على معلومات عامة فقط
- لا يحتوي على معلومات حساسة

### الأفضلية:
- قم بالمزامنة بعد كل مجموعة من التحديثات المهمة
- احتفظ بنسخ احتياطية من ملفات البيانات
- استخدم أسماء ملفات واضحة بالتاريخ

### المشاكل الشائعة:
- **التحديثات لا تظهر**: تأكد من استيراد ملف البيانات الصحيح
- **خطأ في الملف**: تأكد من أن الملف بتنسيق JSON صحيح
- **فقدان البيانات**: استخدم دائماً "تصدير البيانات" قبل المسح

## 🎯 الخلاصة

هذا النظام يسمح بالتعاون بين عدة مسؤولين:
1. مسؤول يقوم بالتحديثات ويصدّر البيانات
2. مسؤول آخر يستورد البيانات ويحصل على نفس التحديثات
3. جميع المستخدمين يرون نفس المحتوى المحدث

**ملاحظة**: هذا حل مؤقت حتى يمكن تطبيق نظام مزامنة تلقائي متقدم.
